Single binary · no runtime required

A coding agent that ships as one file.

gocode is a Go port of opencode. The agent loop, the tools, language-server diagnostics, MCP, and the full terminal interface compile into a single static executable — nothing to install alongside it.

What is in the binary

Everything below is compiled in. There is no Node, no Python, no package manager step.

⌨

Terminal interface

Sessions, a scrollable timeline, model and agent pickers, permission prompts, inline / command and @ file completion, mouse selection and copy.

🔧

14 built-in tools

read, write, edit, apply_patch, glob, grep, bash, webfetch, websearch, todowrite, question, plan and skills — each behind a permission rule.

🩺

Language servers

27 servers detected on PATH. Edits report their own diagnostics in the same turn, so a broken change says so immediately.

🔌

MCP client

stdio and HTTP/SSE servers, OAuth with dynamic client registration, live reconnect, and their tools merged into the registry.

🧠

Any provider

A models.dev catalog is embedded, so 212 providers resolve offline. Anthropic, OpenAI and Gemini wire formats, plus Copilot, Azure and ChatGPT sign-in.

🛡

Permissions that hold

File tools are scoped to the working directory — and the shell is held to it too: a command writing outside it asks first.

Fetching the latest release from GitHub.

Every release ships a SHA256SUMS file. Verify a download with sha256sum -c SHA256SUMS --ignore-missing. On macOS the binaries are unsigned — clear the quarantine flag with xattr -d com.apple.quarantine opencode.

Install

Unpack it, put it on your PATH, run it. That is the whole procedure.

# download the archive for your platform from the Downloads section, then
tar -xzf opencode-*-macos-arm64.tar.gz
chmod +x opencode
sudo mv opencode /usr/local/bin/

opencode --version
# in PowerShell, after downloading the .zip
Expand-Archive .\opencode-*-windows-x64.zip -DestinationPath .
# move opencode.exe somewhere on your PATH, then
.\opencode.exe --version
git clone ….git
cd gocode
make build      # or: go build ./cmd/opencode

./opencode --version

First run

Sign in to a provider, then start a session.

opencode providers login    # pick a provider and a method
opencode                    # start the interface
opencode run "fix the failing test"   # one-shot, no interface
